
# Privacy Policy – Jarvis

Last updated: November 23, 2026

## Overview
Jarvis is a privately operated personal AI assistant
intended for personal use.

## Google Account Access
Jarvis uses Google OAuth 2.0 to access Gmail and
Google Calendar with the account owner's consent.

## Data Usage
Google account data is used to:
- Retrieve and summarize emails
- Read calendar events
- Generate personal briefings and reminders
- Respond to user requests

## Data Storage and Security
Authentication credentials are stored privately
and are not publicly accessible.

Google account data may be processed by configured
third-party AI providers to fulfill user requests.

## Data Sharing
Jarvis does not sell Google user data.

## Revoking Access
Users can revoke access at any time through
their Google Account security settings:

https://myaccount.google.com/connections

## Contact
For privacy inquiries, contact the application
operator through the repository's GitHub profile.
